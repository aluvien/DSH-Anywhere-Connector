# DSH Anywhere

Connect DSH Anywhere on iPhone to DeepSeek Harness. Open the installed plugin's details in Harness, select **开启远程连接**, then display a one-time QR code and scan it in the iPhone app.

Keep Harness open while using remote access. If this computer already uses a separately installed DSH Anywhere Connector, the plugin will use its existing pairing information.

在 Harness 的「插件 → 发现」安装 DSH Anywhere。安装完成后打开插件详情，点击「开启远程连接」，再用 iPhone 扫描一次性二维码。如果已安装独立 Connector，插件会沿用原配对。使用内置 Connector 时，请保持 Harness 运行。
