# Harness 与 iOS 功能对齐验收清单

目标：还原电脑端实际提供的信息和操作，并适配手机阅读。以下全部完成且经过验证后，才可声明整体完成。代码已实现不等于跨端验收通过。

## 当前进度（2026-10-30）

- 开发分支 `codex/harness-ios-parity`，草稿 PR #1；目标创建及真实联调修复已推送；schema 12 生产组件已按顺序升级。
- 生产 Relay、已加载的桌面 Bridge 与已安装 Connector 已按用户确认顺序升级为 schema 12，协议主版本仍为 1。Build 126 已完成签名、上传和 Apple 处理，App Store Connect 确认为 `VALID` / `IN_BETA_TESTING`。
- 原生目标创建使用 `goals.create({agentId, request})`，提供目标和可选总轮次上限；不需要伪造 GoalRef，也不依赖 `/goal` 是否注册。当前存在未完成目标时禁止覆盖；已完成目标可按 Native 语义直接替换，新目标轮次从 0 开始。创建回执、未知结果和重试使用同一持久请求；已存在目标沿用原生 CAS 控制。静态 profile 的 disabled 值不能代表最终运行目录，不据此推断命令实际缺失。
- 真实联调发现并修复：Native 无目标直接返回 undefined 时需保留空基线；手机根目录空路径需转换为 Native `.`；Native 文件异常可能直接抛出，需映射到明确能力/访问错误。独立 AppModel 注入配对存储，使测试不使用或改变开发者的手机配对。
- TypeScript 构建、类型检查和 296 项回归通过（协议 37、Relay 23、Bridge 180、Connector 56），覆盖旧 schema 11 拒绝与新的创建请求。当前修订的真实 Native 流程与 CI 结果见下方最新记录。
- 独立 Native CRUD 验收时禁用测试实例的 goal-round-driver；另行启用该驱动并连接本地确定性模型，验证真实自动轮次、原生 round-limit 阻塞及 activation 解除。真实流式思考、回答和交互工具已另外验收。生产 Harness 不修改此插件。

## 实现说明与阶段性验收记录

以下说明保留各批次当时的限制；当前验收结论以文末“最终功能验收汇总”为准。

- 电脑配置入口：读取 Native `settings.describe` 的 schema/value/base/user、隐藏密钥位置、版本和 live/restart 生效方式；配置与回执只供对应页面读取，不写入聊天 Store、Connector 重放和手机普通事务日志。字符串、数字、布尔、常量枚举、对象、字典与模型数组按原生定义编辑，保留未知字段；数组整体提交，支持增删与调整顺序，避免把数字路径错误地写成对象。未知结构可显式进入 JSON 编辑并校验后应用；隐藏密钥所在数组明确只读，不能用脱敏副本覆盖完整配置。字段可清除用户覆盖，基础值由 Host 合并恢复。保存只调用 `settings.mutate`，保留 expectedRevision 的原子 CAS；发现新版本或字段定义变化时保留草稿并要求显式核对、合并。尚需真实主机配置、重启生效和双端冲突验收。
- 模型服务与插件目录：连接 `llm.listProviders`、`listConfigurableProviders` 和 `pluginInventory.list`，保留已激活/仅声明状态、设置命名空间及路径、声明错误，以及插件启用状态、加载阶段、预设信任来源、默认模式、损坏说明和启用条件。提供方可进入对应原生表单；插件清单遵循 Native 只读能力，可写配置通过命名空间表单修改。已接入 Native `llm.discoverModels({settingsNs, request})`，支持当前草稿的地址、协议及可选临时密钥，发现结果可搜索、多选并只追加新模型到安全草稿，保留已存在模型的未知字段与自定义参数；保存仍使用原生 CAS。发现请求与结果不进入普通事务日志、重放或 Bridge 幂等缓存，任意适配器异常只返回固定错误。配置原始/已解析变更、凭据引用/记录变化、模型适配器注册和插件生命周期只转发标识失效通知，不转发密钥或配置值；手机合并短时间内的刷新，重连时重新读取，编辑页保留修改并显示最新电脑版本，晚到请求按页面代际与身份隔离。真实服务的模型发现、外部文件修改及多端同时保存仍待验收。
- 凭据管理：通过 Native `credentials.describe` 展示 configured/source/writable，`set/unset` 只在原生确认后清理输入，移除前有明确确认；电脑端旧密钥不会返回手机。新密钥、设置表单草稿、未确认请求及原请求身份使用 iOS Keychain，按电脑、配对设备、命名空间与表单路径隔离。钥匙串读取或写入失败时不退回明文存储；原生保存未知时保留同一请求，已证明未提交时可解除重试锁。Bridge 仅记录指纹和脱敏回执，校验内容指纹，不能缓存另一次内容的成功回执；任意适配器异常不会原样写回配置错误。多个页面重试同一请求共享一个在途调用，旧页面回执不能覆盖另一页面的新草稿；切换电脑或配对身份后阻止跨机器提交。尚需真实凭据来源、网络中断、进程重启及实际调用验收。
- 原生搜索与历史分页：全局内容搜索使用 `sessionQuery.searchSessions`，会话内使用 `searchEvents`；保留 Host 排名、摘要、原生位置及索引游标，并绑定查询、作用域和已接收的 Native 页面大小。索引变化要求重新搜索，不能悄悄拼接不同代际结果。旧 Harness 的有限 `sessionController.search` 只作明确标记的有限回退，不制造分页或精确位置。子会话必须校验完整父子地址与模式，查询不激活 Agent。
- 历史读取使用 Native `session.page`，固定原生快照切点并按消息边界分页。单条思考、回答与工具结果保持完整；大页面缩小消息数，单条仍超限则明确提示，不截断内容。初始历史窗口携带精确覆盖区间；手机将重叠区间合并，搜索跳转产生的未加载区间显示独立标记，可继续从电脑补齐。主对话保留加载锚点、停止自动跟随；子任务可读取历史、搜索并打开准确记录。历史行通过同一外层回执原子合并，不能倒退传输水位或覆盖实时计划、目标和运行状态；加载旧用户消息不能把它变成当前轮次。搜索可定位消息、工具和执行记录，显式点击工具结果后打开结构化详情；思考仍默认折叠。尚需真实长历史、滚动与双端验收。
- 可选定时提醒：转发 Native control 的 `schedule` 投影，并通过 Host `sessionProjections.restore` 只读恢复历史会话，保留精确的 fork 继承边界，不自行重算规则、创建计时器或启动 Agent。手机显示一次/定期规则、完整提示词、原始目标时间及到期待处理状态；支持原生更新、明确清空、能力缺省、断线缓存和刷新。投影按 Native 水位与控制流代际隔离，旧快照不能复活已移除提醒，未知可选格式不应中断 jobs/queue/plan 共享控制流。提醒执行仍要求电脑上的原会话保持开启。尚需真实 Host 的创建、触发、删除与双端验收。
- 输入框 `/plan`、`/goal` 走原生命令接口，保留失败草稿和请求身份。
- 问题说明支持 Markdown；问题可跳过；单选自定义答案与选项互斥。
- 计划审阅 intent 经过 Bridge/协议/iOS，匹配审批选项，支持全屏阅读。
- `plan/mode`、`goal/change` 映射到手机状态；历史窗口之外的模式事件仍回放。
- 计划退出入口及目标状态卡、编辑/暂停/恢复/清除入口。
- 目标轮次实时事件、activation 实时事件和打开会话时的只读基线查询；旧查询不能覆盖查询期间到达的新事件。
- 计划 pending：转发原生 control 流中的 plan projection，保留已生效 active 与等待下一步生效 pending；按原生 watermark 拒绝旧更新，控制流重连换代，断线显示待同步。手机不自行模拟 `/plan` 的生效时机，历史回放不覆盖正在显示的原生投影。
- 目标原生控制：编辑目标/总轮次、暂停、恢复、完成和清除使用 goals 原生方法，保留 GoalRef 的 id/revision。Bridge 读取当前版本并保留 Host 的原子 CAS 校验，未知结果保留请求日志；手机表单保留失败编辑，显示其他端新版本并要求显式合并。刷新读取 activation，活跃目标与清除结果不被历史回放覆盖，完成后的完整目标仍可阅读。尚需匹配版本部署后的真实 Host/双端验收。

- 工具详情保留原生 result.meta、完整 content、错误和附件引用。diff 按上下文/增删行折叠，读取按真实行号展示；搜索按文件/路径分组并保留 total/truncated；网页保留来源、摘要、日期、HTTP 状态及截断标记；终端复用 Harness 的尾部退出码/信号契约，基础设施失败不推断退出码。图片/文件复用完整附件预览，未知工具与无效元数据回退原始输出。子调用按原生 rootCallId/parentCallId/subCallId 成树，保留输入、失败与原生起止时间；缺父、非法环和过深分支仍单独可读。工具输入及原始 JSON 可独立展开，全屏阅读保留所有信息；历史未结束工具不再自行脉动为正在运行。尚需真实 Host/手机和超大结果验收。

- 按会话读取 Harness 命令目录，驱动输入建议、命令菜单和原生命令识别；保留输入提示与附件能力字段。打开会话/菜单时刷新，旧 Bridge 404/501 回退。
- 命令/技能注册变化及预设切换触发目录失效，刷新当前可见会话并拒绝晚到的旧目录回复。技能通过 `skills/list` 的原生 request 信封发现，建议和菜单保留技能入口，同名 Host 命令优先；技能仍走用户提示词路径由 Harness 加载。
- 附件命令按 Host input.attachments 声明准入，复用附件事务的 blob、上传凭据、请求身份和有限恢复期限；journal 内部 mode=command 始终转为 command.execute，普通消息重试也保留该区分。结果未知后保留草稿/凭据，成功回执清理事务。尚需真实主机及进程重启恢复验收。
- 计划审阅“继续讨论”及普通提问取消：question.cancel 经 Connector 到 Bridge，以 UserQuestionError/ASK_CANCELLED 错误形状走 Harness 原生恢复路径。任一端显式取消立即结束竞争，关闭 pending 定时器和监听；普通到期/无答题端继续保持原等待策略。取消失败保留卡片。尚需真实双端等待撤销验收。
- 后台任务：Bridge 订阅原生 Session control 流，镜像 jobs baseline/更新，给新连接补快照，重连清理缺席列表，断流标记不可用；手机更多菜单和只读面板显示任务状态、详情、起止时间及可靠运行计时。手机断线也会作废缓存的可用标志。尚需真实主机和视觉验收。
- 服务端队列：同一 control 流镜像 queue baseline/更新，保留 occurrence ID、placement、rpcId 和全部 content；手机区分本机暂存和 Harness 已接收，快照清理本地回显及丢失的接受回执。按项目 ID 接原生 edit/remove/steer，独立请求回执和幂等 journal 防重复；仅纯文字可编辑，避免原生替换内容时丢附件。队列附件通过 Host 原生 attachments 服务补充稳定引用、缩略图和原始文件路径，实时、晚连接快照及离线快照均保留，复用完整文件预览与导出。离线只禁用修改，不禁用原始内容展开及缓存图片预览；缓存预览明确标记，原始文件仍由 Host 授权读取。真实双端验收仍待完成。

- 子代理目录与执行记录：按原生 subagents/list 读取 direct-child catalog，保留 one-shot/continuable、activity、hasChildren 和 diagnostic；手机可递归打开下级目录并查看消息、折叠思考、工具、附件、用量及已有时间数据。历史读取必须匹配 parentSessionId/childSessionId/mode，普通主列表继续省略子代理。continuable 通过原生 subagents/prompt 发送排队/插话，通过 interruptByParent 停止；保留完整父子地址、请求身份、有限重试日志及失败草稿，one-shot 不显示继续发送/停止。支持图片及纯图片消息，由原生 Host 做图片准入与持久化，不接受调用方伪造的持久引用。手机先转为 2048 像素以内的 JPEG，每个草稿最多 4 张、合计 6 MiB，协议限制合计 base64 为 8 MiB。文字和发送方式保存在按机器/父/子地址隔离的共享草稿中，图片另存受系统文件保护的原子文件；乱序保存不能覆盖新版本。提交前先确认图片已保存，未知结果重试沿用同一完整请求；真实接收后仅清理尚未修改的同一份草稿，旧阅读器的回执也更新新阅读器，已接收图片的轻量回执防止遗留文件重新出现。父会话离线不能发送，停止仍交由 Host 按 live Activation 校验。目录监听 catalog 变化和父/子运行状态，合并刷新并拒绝旧回复。完整生命周期计时及真实双端验收仍待完成。
- 提问和审批恢复：提交改为等待真实 resolved 事件，传输/协议失败解除提交锁并保留答案或决定；题目草稿和审批的上次选择按机器/请求持久化，重新打开可显式重试，过期禁用提交，真实解决后清理。重连、协议拒绝或等待超时后查询当前 pending 集合；Bridge 为实时决策和快照附加同一 epoch/revision，手机拒绝旧快照、旧主机事件，清理漏收 resolved 的旧卡片。旧 Bridge 不提供恢复接口时保持原事件路径。子任务记录也显示其 pending 提问和审批。尚需真实双端竞争及掉线验收。
- 工作流：依据桌面持久化的四类 tool-workflow 记录还原运行和成员，按真实 phase 分组，区分缺省、空字符串与普通阶段名；展示完成、失败、取消和所在步骤/轮次关闭后的中断，成员的显式结果不被整体结果替代。消息时间线保留锚点；跨历史窗口的运行保留成员；完整目录补齐较早的记录但不额外插入当前时间线。加载历史期间到达的实时更新会合并，手机按 Native 水位拒绝旧状态。会话及子会话均可打开工作流记录，成员通过父目录确认身份/模式后进入原有子任务阅读器，支持离线已缓存阅读。尚需真实 Host/双端验收。
- 原生轮次结束原因：兼容字符串和结构化 reason，error/aborted 分别标为失败/取消，保留 max-tokens/interrupted；不再把所有对象原因都显示为完成。完整执行过程专用展示仍待后续补齐。
- 文件浏览与导出：使用原生 workspaceFiles/list、readBytes 和 stat，保留 workspaceFileScopeId；目录限定原生工作区，绝对/相对文件读取由 Host 的文件系统权限判断，不以 Bridge 的直接磁盘读取绕过。手机保留回答链接中的原生会话/路径，支持 POSIX、Windows drive 和 UNC 的 dsh-resource 地址，以及本地文件链接；工作区目录、回答中的文件链接和上传记录分别可查看。按 192 KiB 分段下载，每段对照前一段版本，Bridge 读取后再次 stat；版本/路径变化拒绝导出。文件 bytes 不进入聊天重放缓存或手机持久化 Store。完整下载后才能预览/分享，失败或取消删除临时文件；已完成文件由预览生命周期持有，避免打开系统预览/分享时提前删除。手机单文件上限 64 MiB，1 MiB 内 UTF-8 文本支持换行、选择与 Markdown 阅读，其余格式使用系统 Quick Look 或分享。原生附件的完整文件读取见下一项；仅有旧上传凭据且尚未产生持久化消息的记录仍只有元信息。相关资源的 HTML 预览、真实权限拒绝与跨端操作仍待完成。
- 完整附件：通过 Cordis 可选的 attachments 服务读取 fileHostPath/imageHostPath，保留持久化消息中的文件和图片引用，避免把客户端提供的路径或 sha256 自行拼成磁盘地址。手机附件卡和对话文件列表可下载原生存储的完整文件，名字缺少扩展名的图片按 Host mediaType 补齐预览文件名；下载显示名只作为本地文件名使用。手机展示适合屏幕的图片并提供系统预览与完整文件分享；Host 未提供路径时仍保留旧缩略图/元信息。真实 Host 存储后端与分享操作仍待验收。
